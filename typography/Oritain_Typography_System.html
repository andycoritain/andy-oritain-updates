--font-offline Calibri → Carlito → Helvetica
Calibri (primary) Word · PDF · Print only Never in platform UI

Calibri is the default font in Microsoft Word and Outlook. Forensic reports sent to clients must render as-authored — Inter and Gotham are not bundled with Office and substitute unpredictably, breaking layout and credibility.

Calibri must never appear in platform CSS, web UI, or mobile app bundles. It has no woff2 format and renders poorly on screens below 16px. Its sole purpose is offline document fidelity.

Important: When authoring Word reports or PDF exports, use Calibri 11pt body and 14pt headings. Do not use Inter or Montserrat in Word — they will not render correctly on client machines without those fonts installed.

--font-ui Inter → system-ui → Segoe UI
Inter (primary) All platform UI Variable font Default when in doubt

Purpose-built for screen UI. Optimised hinting at 11–14px — exactly the range where data-dense tables, form labels, and navigation items live. Available as a variable font: one file covers all weights.

400 Regular for body and table cells. 500 Medium for labels, navigation, and emphasis. 600 SemiBold for strong hierarchy only. Never 700+ — it clashes with Oritain's clean visual tone.

@font-face { font-family: 'Inter'; src: url('/fonts/Inter-Variable.woff2') format('woff2') tech(variations); font-weight: 100 900; font-display: swap; } :root { --font-ui: 'Inter', system-ui, -apple-system, 'Segoe UI', Roboto, Arial, sans-serif; } .table-body { font-family: var(--font-ui); font-size: 13px; font-weight: 400; } .table-header { font-family: var(--font-ui); font-size: 12px; font-weight: 500; } .nav-label { font-family: var(--font-ui); font-size: 13px; font-weight: 500; } .caption { font-family: var(--font-ui); font-size: 12px; font-weight: 400; }

Web font strategy for enterprise SaaS

Why Cloud.typography is a liability for the Oritain platform — and the right approach instead.

The core problem: Cloud.typography is a third-party CDN dependency. For enterprise SaaS, every external dependency is a potential point of failure, a security review flag, and a network access problem. The risks below are not theoretical — they affect real Oritain clients today.

🔒 Network restrictions

Enterprise and government clients run on locked-down networks that block external CDN requests by default. Cloud.typography fails silently — reverting to your fallback stack at the worst moment.

📋 SOC 2 & security audits

Third-party font CDNs are flagged as undeclared external data flows in SOC 2 and ISO 27001 audits. Every pageview pings Hoefler's servers — a data flow that must be declared and justified.

✈️ Air-gapped environments

Some Oritain clients — food safety regulators, government agencies — operate in restricted environments with no external internet access. Cloud.typography will never load for these users.

🛡️ CSP headers

Strict Content Security Policy headers block external font-src by default. Every environment (prod, staging, dev) needs explicit allowlisting — easy to miss, causes silent failures that are hard to debug.

📱 Mobile apps

Cloud.typography is web-only. A React Native or native iOS/Android app needs a separate desktop/app licence and bundled font files — two licences, two delivery mechanisms, ongoing cost.

💡 The right approach: self-hosted Montserrat

Montserrat Medium is the closest open-source geometric sans to Gotham. SIL OFL licensed, free forever, self-hosted. One woff2 file. No CDN. No subscription. No security flags. Works everywhere.

CSS custom properties */ :root { --font-display: 'Montserrat', 'Gotham Medium', 'Century Gothic', sans-serif; --font-ui: 'Inter', system-ui, -apple-system, 'Segoe UI', sans-serif; --font-offline: 'Calibri', 'Carlito', Helvetica, Arial, sans-serif; } /* 5.
